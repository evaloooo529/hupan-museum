添加装置

导入 STL 后，装置会跟着指针。在地面上点击放下。跟着指针时，右键或双指拖动可绕自身转一圈，右键或双指点按可删除。放下之后可以拖动改位置，拖透明圆点改大小，右键或双指拖动绕自身旋转。

添加装饰

点一件，它会跟着指针。在地面上点击放下。跟着指针时，右键或双指拖动可绕自身转一圈，右键或双指点按可删除。放下之后可以拖动改位置，右键或双指拖动绕自身旋转。

连接 GitHub

粘贴一个可以读写私有仓库 hupan-museum-shows 的 GitHub 令牌。它只保存在这台设备的浏览器里，用来在不同设备之间同步同一份策展。

在 GitHub 新建一个细粒度令牌，只勾选仓库 hupan-museum-shows，权限里勾选 Contents（内容），级别选 Read and write。
